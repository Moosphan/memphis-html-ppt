# Memphis 模板设计规范

> 本文档是 26 个页面模板的 SVG 设计蓝图。
> 设计语言参考: [ppt-master/sugar_rush_memphis](https://github.com/hugohe3/ppt-master/tree/main/examples/ppt169_sugar_rush_memphis/svg_final)
> 核心风格: Impact 粗黑标题 + 4px 描边圆角卡片 + 色块顶栏 + Memphis 几何图标

---

## 全局设计系统 (Design Tokens)

### 画布
- 尺寸: 1280 × 720px (16:9)
- 安全边距: 四周 60px

### 色彩
```
底色:      #FFF8EE
深色:      #1A1A2E (文字/描边)
灰调:      #5C5C7A (副标题/辅助)

强调色 (卡片顶栏/装饰):
  Coral:   #FF6B4A   Teal:    #00B8D9
  Yellow:  #FFD93D   Mint:    #00C896
  Pink:    #FF3DA5

文字强调色 (浅底上文字, ≥ 4.5:1):
  DeepRed: #C0392B   ← 替代 #FF6B4A 做文字色
```

### 字体 (4 级)
```
L1 — 主标题:    Impact/Arial Black, 48-72px, 900, letter-spacing 1
L2 — 卡片标题:  Impact/Arial Black, 24-28px, 900, letter-spacing 2
L3 — 正文:      Arial/Microsoft YaHei, 16px, 700
L4 — 辅助:      Arial, 12-14px, 600-900
```

### 卡片系统
```
统一:     rx=14, stroke=4px #1A1A2E, 无阴影
顶栏色块: 大卡 56px / 小卡 40px 高
内容底:   #FFF8EE (与画布同色)
```

### 要点列表
```
圆点:  r=5-6, 色块填充 + #1A1A2E stroke 2px
文字:  Arial 16px 700, #1A1A2E
强调:  <tspan fill="#C0392B" font-weight="900">关键词</tspan>
```

### Header (每页必有)
```
左侧竖色条: x=60, y=55, w=14, h=60, 色块(每页不同)
标题:       Impact 48px 900, #1A1A2E, x=90
副标题:     Arial 18px 700, #5C5C7A, letter-spacing=3
右上:       2×2 小彩色方块 22×22px
```

### Footer (每页必有)
```
左: Arial 12px 600, #5C5C7A
右: Impact 14px 900, #1A1A2E, "XX / XX"
```

### Memphis 装饰
```
图标:   闪电/星星/爱心/音符, scale 2.0-2.25, 色块填充, 在卡片顶栏内
圆点:   r=5-10, 色块+描边, 散布安全边距
方块:   22×22, 色块+描边, 右上角 2×2
三角:   polygon, 色块+描边, 角落
虚线圆: dasharray, 低 opacity, 背景
虚线线: dasharray="6,6", 流程连接
```

## 族 1: HERO 大字报型

### 1. hero-cover — 封面

**设计理念:** 震撼开场。一个大标题占据视觉 60%，配一个辅助区域建立语境。像杂志封面一样有冲击力。

**布局网格:**
```
┌──────────────────────────────────────────────────────────────┐
│ [Section Chip]                               [装饰: 点阵]    │
│                                                              │
│  ┌─────────────────────────┐  ┌──────────────────────────┐  │
│  │                         │  │                          │  │
│  │   HERO TITLE            │  │   [视觉区域/插图]        │  │
│  │   超大字体, 2-3 行       │  │   可放图片、图标、图表    │  │
│  │                         │  │   或抽象几何图形          │  │
│  │   副标题 (1-2 行)       │  │                          │  │
│  │                         │  │                          │  │
│  │   简短说明文字           │  │                          │  │
│  │                         │  ├──────────────────────────┤  │
│  │   [Tag1] [Tag2] [Tag3] │  │ Insight │ Signal         │  │
│  └─────────────────────────┘  └──────────────────────────┘  │
│                                                              │
│ [装饰: 波浪线]                         [Page Counter]        │
└──────────────────────────────────────────────────────────────┘
```

**布局比例:** 左 45% 文字区 / 右 55% 视觉区
**标题区:** 640×600px, 圆角卡片, 白底, Hero 卡片样式
**视觉区:** 680×506px, 圆角卡片, 浅底, 内含占位图框
**底部小卡片:** 2 个 194×108px 的 Insight/Signal 卡片, 靠右下
**装饰:** 右上点阵 + 左下波浪线 + 左上三角标记

**色彩策略:** 视觉区可用 1 个强调色做大色块点缀 (如圆形/方形几何)
**文字预算:** 标题 20 字, 副标题 30 字, 说明 40 字

## 族 2: SPLIT 左右分栏型

### 2. narrative-split — 叙事分栏

**设计理念:** 左侧放核心观点 (大卡片), 右侧放支撑论据 (2 个小卡片)。像一篇社论的排版: 论点+论据。

**布局网格:**
```
┌──────────────────────────────────────────────────────────────┐
│ [Section Chip]                               [装饰: 点阵]    │
│   PAGE TITLE                                                   │
│   副标题说明                                                   │
│                                                              │
│  ┌──────────────────────┐  ┌──────────────────────────────┐ │
│  │                      │  │  CARD TITLE                  │ │
│  │  MAIN NARRATIVE      │  │                              │ │
│  │                      │  │  要点 1: 说明文字            │ │
│  │  核心观点段落         │  │  要点 2: 说明文字            │ │
│  │  (2-3 段, 有呼吸感)  │  │  要点 3: 说明文字            │ │
│  │                      │  │                              │ │
│  │                      │  │  [小色块装饰]                │ │
│  │                      │  ├──────────────────────────────┤ │
│  │                      │  │  SECONDARY TITLE             │ │
│  │                      │  │  补充说明或上下文             │ │
│  └──────────────────────┘  └──────────────────────────────┘ │
│                                                              │
│ [装饰: 波浪线]                         [Page Counter]        │
└──────────────────────────────────────────────────────────────┘
```

**布局比例:** 左 48% 主卡片 / 右 52% 双卡片(上下各 50%)
**左卡片:** 680×560px, Hero 卡片样式, 白底
**右上卡片:** 680×268px, Primary 卡片样式, 浅底
**右下卡片:** 680×268px, Secondary 卡片样式, 白底

**色彩策略:** 右上卡片标题可用 1 个强调色色块做标记
**文字预算:** 标题 20 字, 主叙事 120 字, 每个要点 30 字

## 族 4: GRID 网格型

## 设计验证清单

每个 SVG 完成后, 用以下清单验证:

- [ ] 画布 1600×900, 安全边距 80px
- [ ] Section Chip 左上, Page Counter 右下
- [ ] 标题用 Georgia/Serif, 正文用 Montserrat/Sans
- [ ] 标题字号 ≥ 正文的 3 倍
- [ ] 每页最多 1 主色 + 1 辅色
- [ ] 硬阴影 (无模糊)
- [ ] 描边 4-6px, 一致
- [ ] 卡片圆角 24-32px
- [ ] 装饰元素在四角, 不干扰内容
- [ ] 留白 ≥ 40px 间距
- [ ] 文字行宽 ≤ 60 字符
- [ ] 视觉焦点明确, 一眼知道"这页在说什么"
- [ ] 整体感觉: 杂志级排版, 非网页卡片堆叠
